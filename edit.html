💾 Save directly to GitHub

Connect once with a personal access token, then click Save to GitHub to send your edits straight to the repository — no downloads. The token is kept only in this browser.

How to create the token (one-time setup)
  1. On GitHub: click your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose this repo.
  3. Permissions → Repository permissions → set Contents to Read and write. Leave everything else off.
  4. Generate it, copy the token, and paste it above.

Anyone with this token can change your repository. Never paste it on a shared or public computer, and revoke it anytime from that same GitHub page if it ever leaks. This connection can only commit files — it cannot touch settings, pages, or other repositories.
